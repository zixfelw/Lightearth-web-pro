Cau Hinh Thiet Bi JSON - Solar Monitor

Huong Dan Nhap Lieu JSON

Buoc 1: Hieu Cau Truc JSON

Cau hinh thiet bi duoc luu tru duoi dang JSON voi cac truong sau: 

{
  "devices": [
    {
      "deviceId": "P250617024",
      "name": "He thong Nha A",
      "model": "SUNT-8.0kW-T",
      "manufacturer": "YS Tech (YiShen)",
      "sw_version": "V12.59",
      "hw_version": "V12.43",
      "capacity_kw": 8.0,
      "battery_capacity_kwh": 10.24,
      "pv_panels": 16,
      "enabled": true,
      "ha_integration": true
    }
  ]
}

Buoc 2: Giai Thich Cac Truong

Truong Kieu Du Lieu Mo Ta Trang Thai
deviceId String Ma thiet bi (VD: P250617024) Bat buoc
name String Ten hien thi (VD: "Nha A") Bat buoc
model String Loai bien tan (VD: SUNT-8.0kW-T) Tuy chon
manufacturer String Nha san xuat (VD: YS Tech) Tuy chon
sw_version String Phien ban phan mem Tuy chon
hw_version String Phien ban phan cung Tuy chon
capacity_kw Number Cong suat bien tan (kW) Tuy chon
battery_capacity_kwh Number Dung luong pin (kWh) Tuy chon
pv_panels Number So luong tam PV Tuy chon
enabled Boolean Trang thai kich hoat Mac dinh: true
ha_integration Boolean Ket noi voi Home Assistant Mac dinh: false

Buoc 3: Cach Nhap Lieu

  1. Chuyen sang tab "Chinh Sua JSON"
  2. Sao chep template o tren hoac nhap JSON cua ban
  3. Chinh sua cac truong theo thong tin thiet bi thuc te
  4. Nhan nut "Kiem Tra Cu Phap" de xac nhan JSON hop le
  5. Nhan nut "Luu Cau Hinh" de luu

Luu Y Quan Trong

  • DeviceId phai chinh xac voi ma tren he thong Lightearth
  • Model co the lay tu Home Assistant (tab "Thong Tin HA")
  • Dam bao JSON co dinh dang dung (khong thua dau phay, dau ngoac)
  • Gia tri boolean chi co the la true hoac false
